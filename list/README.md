# Сериализация двусвязного списка (Профессиональная версия)

## Описание
Проект реализует сериализацию и десериализацию двусвязного списка с произвольными указателями (rand).

## Особенности
- Время: O(n)
- Память: O(n)
- Без утечек памяти (деструктор)
- Проверка ошибок файлов
- Валидация входных данных

## Идея
Указатели нельзя сохранять напрямую → заменяем их индексами.

## Сборка
mkdir build
cd build
cmake ..
make
./list_serialization
